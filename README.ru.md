<h1 align="center">Show My Copy</h1>

<p align="center">История буфера обмена для macOS по одному хоткею.</p>

<p align="center"><a href="README.md">English version</a></p>

## Что будет уметь

- **История в фоне.** Всё, что копируешь, собирается незаметно: текст, форматированный текст, картинки и файлы.
- **Окно по хоткею.** Настраиваемое сочетание (по умолчанию ⌘⇧V) открывает последние записи поверх любого приложения. Поиск, стрелки, Enter — скопировать.
- **Кнопка в Пункте управления** на macOS 26.
- **Пароли скрыты.** Записи из менеджеров паролей показываются маской, пока их не раскроешь, шифруются на диске и удаляются через заданное время.
- **Лимиты задаёшь сам.** Сколько записей хранить и сколько места на диске и в памяти занимает история.
- **Без иконки в строке меню и в Dock.**
- **Приватность.** История остаётся на твоём Mac. Без аналитики и сети.

Модель безопасности — в [SECURITY.md](SECURITY.md).

## Сборка

Нужен Xcode 26.

```sh
make lint   # SwiftLint + swift-format
make test   # юнит-тесты
```

Открой `ShowMyCopy.xcodeproj` и запусти схему `ShowMyCopy`.
