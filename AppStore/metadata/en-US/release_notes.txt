Codes: a right-click or a two-finger swipe on a code's row offers Copy Code and Remove Account, like an entry's row; a full swipe never removes an account. Settings → Codes edit an account's service and account names; the secret stays. Showing the codes with the button or ⌘K now scrolls the list to them also when it was scrolled down.

Security: each saved password is bound to its history record and the code accounts file to its place, so encrypted data moved to another record or file does not open there. Data saved by earlier versions still opens.
